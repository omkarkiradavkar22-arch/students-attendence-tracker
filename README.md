# Student Attendance Management System - Demo

A quick demo-ready attendance project built with HTML, CSS and JavaScript.

## Features
- Admin and Teacher login
- Teacher-specific assigned subject
- Student attendance: Present / Absent / Late
- Optional remarks
- Mark all present
- Submit & Lock attendance
- Local audit log
- Search students
- Dashboard statistics
- Dark mode
- Responsive UI

## How to Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Important Note
This version is designed for a fast classroom/demo presentation. Authentication and locking are simulated in the browser using JavaScript + localStorage. For a truly secure production system, use Node.js/Express, MongoDB, bcrypt password hashing and JWT authorization on the backend.
